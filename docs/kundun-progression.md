# Box of Kundun Excellent progression

The live reward design is described below. Kundun +1 through +5 stop at the Star/pre-Pink base tier. No Pink/Blue equipment is eligible. Ancient pools and normal bonus boxes are unchanged.

Each opening gives **one Excellent +0 item**, never an entire set. No sockets. Shared server Luck, ADD and supported Skill behavior is preserved; these do not count as Excellent options.

| Box | One EXC option | Two distinct EXC options |
| --- | ---: | ---: |
| +1 | 50% | 50% |
| +2 | 60% | 40% |
| +3 | 70% | 30% |
| +4 | 80% | 20% |
| +5 | 90% | 10% |

Always one or two EXC options, never duplicates. Higher base-item strength is balanced by fewer double-option rolls. This does not guarantee that Excellent equipment is weaker than every upgraded normal or Ancient item.

## Selection probabilities

Armor **60%**, weapons/books **30%**, shields **10%** at every tier. Each eligible class receives an equal share within the category. Armor variants split their class share equally, then one eligible piece is selected equally. Weapon/book and shield variants split their class share equally. Shared items can be selected through more than one class; these intended routes are additive, without multiplying the weight of a class with more variants.

Armor class share: +1 has six classes at **10% overall each** (no SUM armor); +2–+5 have seven classes at **60/7% overall each**. Weapons/books: seven classes at **30/7% overall each**. Shields: DW/DK/Elf/MG/DL at **2% overall each**, no SUM/RF shields. MG has no helm; RF has no gloves.

## Mapping and eligibility checks

All 234 distinct selected item definitions exist and have the intended server class qualification. No class restrictions were changed. Advancement-only pieces retain those requirements. Client names are used above with differing server aliases shown. Book of Sahamutt is client Book of Samut at 5/21; Mystery Stick is server Mistery Stick at 5/14; Big Round Shield is client Large Round Shield at 6/10. Storm Hard Glove is client Holy Storm Claw at 0/33. These aliases are single items, not extra rewards.

Existing characters/items are not converted. Only wrapper 14/11 source levels 8–12 are replaced; drops from monsters, shop placement, Candy variants, Star, Chocolate, Ribbon/BC and Ancient opening pools are not altered. The one-time update preserves subsequent administrator edits. No client data, packet or asset changes are required for Kundun.
