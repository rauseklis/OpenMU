# Skill requirements

Already learned skills have no character-level minimum for casting, for any
class. This includes Master variants, online play, offline attacks and offline
buffs. Resetting a character therefore does not disable a learned skill solely
because its character level is lower.

Learning levels on scrolls, orbs, crystals and parchments still apply. Dark Horse
retains its equipment level requirement. Class qualifications, master-tree
prerequisites, other equipment requirements and cooldowns still apply.

All required stats and resources remain mandatory. If Evil Spirit requires 220
energy, 219 energy is insufficient; at 220 the energy check passes, provided all
other requirements are satisfied. The same rule applies to strength, agility and
leadership. Mana and AG are checked before a successful cast consumes them.

This changes casting behavior without rewriting configured learning or equipment
requirements. Existing skills and newly initialized configurations use the same
policy. No live database override is required.
