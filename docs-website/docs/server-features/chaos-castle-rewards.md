# Chaos Castle rewards

The surviving winner on both Emberion worlds receives two independent reward rolls:

- A 90% chance for one random Jewel of Chaos, Bless, Soul, Creation, or Life. Jewel selection is unchanged.
- A separate chance for one existing Ancient reward box, according to the table below.

| Castle | Ancient reward chance | Box distribution after a successful roll |
| --- | --- | --- |
| CC1 | 0% | None |
| CC2 | 5% | Box of Luck |
| CC3 | 10% | Box of Luck |
| CC4 | 15% | Box of Luck |
| CC5 | 20% | 80% Box of Luck / 20% Silver Box |
| CC6 | 25% | Silver Box |
| CC7 | 30% | 85% Silver Box / 15% Golden Box |

CC5 therefore awards Luck on 16% of victories and Silver on 4%; CC7 awards Silver on 25.5% and Golden on 4.5%. A winner can receive both a jewel and a box. Rewards retain the existing winner-owned ground-drop delivery. Players must survive and remain on the event map to qualify.

The boxes retain their existing contents and item-generation rules:

- Luck: Hyperion, Barnake, Fase, Cloud.
- Silver: Garuda, Heras, Argo, Eplete, Semeden, Chamer.
- Golden: Hyon, Anubis, Aruan, Gaion, Agnis, Chrono, Trite.

An existing database receives a one-time reward update at startup. Subsequent restarts preserve administrator edits. No Blood Castle, Devil Square, monster loot, other box contents, experience, VIP, or economy settings are changed.
